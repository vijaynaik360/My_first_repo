//GIT FIRST CLASS//
**Initialise git repo**
git init

**check status of git repo**
git status

**adding files to staging area**
git add

** To commit **
git commit -m "message"


//GIT SECOND CLASS//
**To remove filr from staging area*
git rm --cached <filename>


**To check what we have changed in commits**
git log -p

**to check remote repo present or not to push or pull**
git remote -v

**TO add remote repository**
git remote add origin <link>


**To create git branch**
git branch Main


**To push code from local branch to remote repo**
git push -u origin main

**To switch another branch**
git checkout <branch name>

**To push for first time from new branch**
git push --set-upstream origin vijay



**To fetch meta data from remote repo**
git fetch

**To fetch and merge data from remote*
git pull
