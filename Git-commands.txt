//GIT FIRST CLASS//
**Initialise git repo**
git init

**check status of git repo**
git status

**adding files to staging area**
git add

** To commit **
git commit -m "message"


//GIT SECOND CLASS//
**To remove filr from staging area*
git rm --cached <filename>


**To check what we have changed in commits**
git log -p

**to check remote repo present or not to push or pull**
git remote -v

**TO add remote repository**
git remote add origin <link>


**To create git branch**
git branch Main


**To push code from local branch to remote repo**
git push -u origin main

**To switch another branch**
git checkout <branch name>

**To push for first time from new branch**
git push --set-upstream origin vijay



**To fetch meta data from remote repo**
git fetch

**To fetch and merge data from remote*
git pull


//git rebase
**To make linear from another branch commits**
Lets say if main branch has commits a->b->c and vijay branch has commits d->e
git rebase main (on checkout vijay) command will make vijay branch commits as a->b->c->d->e

**to delete previous commits**
git rebase -i head ~3 will delete prvious last 3 commits


**To go to previous commits without changing latest commit**
git revert

**To go to previous commits with deleting latest commit**
git reset
