//Links
link- file shortcut
If we make any change it will reflect to original file or link
There are 2 types of link
1. soft link- it is shortcut to the file if we make any changes to the original file it will reflect in link , if the original file is deleted then link does not work.
syntax: ln -s filename linkname
2. Hard link - It is a shortcut to the file if we make any changes to the original file it will reflect in link, if the original file is deleted then still link will work
syntax: ln filename linkname
